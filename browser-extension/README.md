# Bandu Reader Browser Bridge

## English

This optional Chrome/Edge extension sends selected webpage text to the Bandu Reader.
It works with the online reader and can be used with Codex in a browser, as well as ordinary webpages.

### Install for personal use

1. Open `chrome://extensions` or `edge://extensions`.
2. Turn on **Developer mode**.
3. Choose **Load unpacked**.
4. Select this `browser-extension` folder.

### Use

1. Select text in a webpage or browser-based Codex.
2. Right-click and choose **Send selection to Bandu Reader**.
3. The online reader opens with the selected text ready to read.

You can also select text and click the extension icon. The extension keeps the selected text in local browser extension storage only until the reader receives it. The text is not put into the URL and is not uploaded by the extension.

The desktop Codex app is not a webpage, so this extension cannot read its selection directly. For desktop Codex, copy the response and use **Read Clipboard** in Bandu Reader.

## 中文

这是一个可选的 Chrome / Edge 浏览器扩展，把网页中选中的文字送进伴读 Reader。
它可以用于浏览器里的 Codex，也可以用于普通网页。

### 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 打开右上角的**开发者模式**。
3. 点击**加载已解压的扩展程序**。
4. 选择这个 `browser-extension` 文件夹。

### 使用

1. 在网页或浏览器版 Codex 中选中文字。
2. 右键选择 **Send selection to Bandu Reader / 发送到伴读**。
3. 在线版伴读会打开，并准备好这段文字。

也可以选中文字后直接点击扩展图标。扩展只会把选中的文字暂时放在浏览器本地扩展存储里，伴读接收后就删除；文字不会放进 URL，也不会由扩展上传。

桌面版 Codex 不是网页，浏览器扩展无法直接读取它的选区。桌面版请复制回答，再在伴读中点**读取剪贴板**。
